# Fake News Detection Using Machine Learning

An offline machine learning system for detecting potentially fake and real news articles.

## Project Status

Phase 1 - Environment and project setup

## Planned Technology

- Python
- Scikit-learn
- NLP
- Transformers
- FastAPI
- React
- SQLite

## Main Features

- Fake/Real news classification
- Confidence and uncertainty estimation
- Explainable predictions
- Batch analysis
- Prediction history
- Analytics dashboard
- Offline inference
